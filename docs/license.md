## Attributing the data

Wherever you show BombayChitra maps or data, credit OpenStreetMap and Overture Maps:

> © OpenStreetMap contributors · © Overture Maps Foundation

with links to <https://www.openstreetmap.org/copyright> and <https://docs.overturemaps.org/attribution/>. The tiles
carry this attribution, so MapLibre displays it in the corner of the map automatically. A dataset built with
`SKIP_OVERTURE=1` only needs the OpenStreetMap credit.

## Share-alike

The ODbL is a share-alike licence for **databases**. If you publicly use a database derived from BombayChitra data
(for example, you add your own records to `bombaychitra.db` and offer it as a service), you must make that derived
database available under the ODbL. Rendered maps and images ("produced works") only require attribution. See the
[OSMF licence FAQ](https://osmfoundation.org/wiki/Licence/Licence_and_Legal_FAQ) for details.
